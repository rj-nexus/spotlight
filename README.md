# Spotlight Theme

A dark, modern, builder-first theme for [RJ CMS](https://rjnexus.org).

**Version:** 0.1.0-beta &nbsp;|&nbsp; **License:** MIT

> **Beta notice.** Spotlight is in beta testing. Some bugs and unfinished parts are expected, and things may change before the stable release. Feedback and bug reports are welcome.

## About

Spotlight is a customizable, dark-first theme made for product showcases and content creators. It integrates with RJBuilder, so you control the layout, colors and content from the admin panel.

## Features

- **RJBuilder integration:** custom Glass Header and Cinematic Hero widgets.
- **Dynamic Customizer:** live CSS variables for colors, typography and layout.
- **Glassmorphism UI:** frosted glass effects on a dark design.
- **Responsive:** desktop, tablet and mobile.
- **Multilingual:** built-in language switcher with RTL support.
- **Page templates:** Contact, Landing and Full-Width.

## Requirements

- RJ CMS 1.0.0 or newer
- PHP 8.2 or newer

## Installation

1. Clone or download this repository into the RJ CMS themes directory:

   ```bash
   cd rj-content/themes
   git clone https://github.com/rj-nexus/spotlight.git
   ```

2. Log in to the RJ CMS admin panel.
3. Go to **Appearance > Themes**.
4. Find **Spotlight** and click **Activate**.
5. Open the **Customizer** to set your colors and fonts.
